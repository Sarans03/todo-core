\# Todo.Core



Простая библиотека для управления списком задач (todo-list) на C# / .NET 8.



\## Возможности



\- Создание задач с уникальным идентификатором (`Guid`)

\- Отметка задач как выполненных / невыполненных

\- Переименование задач

\- Поиск задач по подстроке (регистронезависимый)

\- Сохранение и загрузка списка задач в формате JSON



\## Структура решения



\- `Todo.Core` — библиотека классов (ядро)

\- `Todo.Core.Tests` — юнит-тесты (xUnit)



\## Сборка и тесты

bash

dotnet restore

dotnet build -c Release

dotnet test -c Release





\## CI/CD



\- \*\*CI\*\*: автоматическая сборка и тесты при push в `main` и при pull request

\- \*\*CD\*\*: автоматическая публикация NuGet-пакета в GitHub Packages после успешного CI
